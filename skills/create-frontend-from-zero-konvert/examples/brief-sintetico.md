# Exemplo sintético: página para aulas de cerâmica

- **Produto:** página inicial para uma oficina fictícia.
- **Público:** pessoas interessadas em conhecer atividades manuais; a familiaridade é desconhecida.
- **Tarefa principal:** entender as aulas e consultar opções de contato.
- **Escopo:** interface nova responsiva; conteúdo fictício identificado; nenhum serviço de pagamento ou formulário real.
- **Suposição:** sem identidade fornecida, criar direção visual original e documentar as escolhas.
- **Verificação:** iniciar localmente, abrir em tela estreita e desktop, percorrer teclado e conferir que contatos simulados não prometem integração real.
