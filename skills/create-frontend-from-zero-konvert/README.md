# Create frontend from zero

Use `create-frontend-from-zero-konvert` to plan, implement, and verify a new frontend from a product brief. Existing interfaces and approved audit findings remain the responsibility of the audit and reference-execution skills. Install all three skills side by side to reuse the audit knowledge base and the executor's browser tools. Agent routing and build quality are not yet measured.

The skill covers discovery and briefing, stack choice for empty projects, visual foundations with verifiable WCAG 2.2 limits, a per-page component and state inventory that reuses the auditor's knowledge units as acceptance criteria, content/SEO/performance and measurement rules, and a definition of done with a delivery-report template. Synthetic examples show a landing brief, an e-commerce brief and a delivery report.
