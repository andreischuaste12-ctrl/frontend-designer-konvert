# Knowledge-unit editorial standard

Units are inspection prompts, not evidence that a problem exists. Author skill content in Portuguese; repository documentation stays in English. Keep agent-facing material inside the installed skill. A unit addresses one problem and has one independently testable acceptance criterion. IDs are globally unique `UXK-<journey>-NNN`: CHK checkout, FRM forms, NAV navigation, ERR errors and recovery, DSH dashboards, GEN transversal.

Use a level-three heading `### UXK-CHK-001 — Title` followed by the exact fields `Contexto`, `Estados`, `Quando se aplica`, `Exceções`, `Evidência a coletar`, `Método`, `Prioridade padrão`, `Recomendação`, `Critério de aceite`, `Preservar`, `Dependência externa`, `Métrica a monitorar`, and `Fonte`, formatted as `- **Field:** value`. Allowed states are `normal`, `carregando`, `erro`, `sucesso`, `vazio`, `recuperação`; methods are `automático`, `inspeção`, `hipótese`; priorities P0–P3. A hypothesis cannot default to P0. Explain applicability and exceptions; avoid universal numeric claims across platforms. Automated results require contextual review, never certification by themselves.

Commercial context touching pricing, delivery, payment or installments is marked `[comercial]` and starts with `pendente` dependency. Only an authorized owner can resolve actual commercial rules. Collect synthetic evidence in an authorized environment, with no real transactions or personal data. Monitoring metrics are suggestions, never invented outcomes. Sources not opened must be marked `não verificada`. Record a verification date and reviewer only when source and claim were actually checked; availability is not verification of a claim.

The [coverage map](coverage-map.md) reports guidance, verification or tests using existing unit IDs; labels do not prove that agents, users or stacks were evaluated. Update the map when coverage changes and retain `—` for gaps. Run `node scripts/validate-repository.mjs` and the root tests before requesting review. Structural checks cannot validate evidence, accessibility, quality, or source truth.
